# كود تجربة: أثر اللهجة العراقية على كود ChatGPT

هذا الكود ينفّذ منهجية الورقة كاملة، على أربع خطوات. كل خطوة ملف Python مستقل.

| الخطوة | الملف | ماذا يفعل |
| --- | --- | --- |
| 1 | `01_prepare_data.py` | يجهّز جدول المسائل الـ 80 لتكتبوا فيه الصيغة العراقية |
| 2 | `02_generate.py` | يرسل كل مسألة إلى ChatGPT بالصيغ الأربع ويحفظ الردود |
| 3 | `03_evaluate.py` | يشغّل الاختبارات ويقيس جودة الكود |
| 4 | `04_analyze.py` | يحسب الإحصاءات ويطلع جداول القسم ٤ من الورقة |

الصيغ الأربع هي: الإنجليزية، والفصحى، واللهجة العراقية، واللهجة العراقية بعد ترجمتها للإنجليزية (سؤال البحث الرابع).

المسائل مأخوذة من HumanEval-XL (رخصة MIT، الملف `data/HumanEval-XL-LICENSE`). فيه 80 مسألة Python متوازية بالإنجليزية والعربية الفصحى، مع اختباراتها.

## الخطوة 1: كتابة الصيغة العراقية

```bash
python 01_prepare_data.py
```

يطلع ملف `data/problems.csv`. افتحيه بـ Excel أو LibreOffice (بترميز UTF-8)، واملئي هذه الأعمدة:

| العمود | ماذا تكتبين |
| --- | --- |
| `msa_description` | النص الفصيح جاهز، راجعيه وصححي أي خطأ بالترجمة |
| `msa_reviewed` | اكتبي `yes` بعد المراجعة |
| `literal_warning` | إذا مكتوب فيه `check`، معناه كلمات بين علامات تنصيص انترجمت للعربي. الاختبارات تنتظر الكلمة الإنجليزية، مثلاً `'zero'` صارت «صفر» و`"YES"` صارت «نعم». رجّعيها إنجليزي بالنص الفصيح، وبعدها امسحي التحذير |
| `iraqi_description` | اكتبي المسألة مثل ما يكتبها طالب عراقي برسالة |
| `iraqi_writer` | حرف أو اسم الكاتب (لازم كاتبين على الأقل) |
| `dialect_level` | `light` أو `medium` أو `heavy` |
| `meaning_verified` | `yes` بعد ما شخص ثالث يقرأ النص العراقي ويأكد إن المعنى نفسه |

**مهم:** اكتبي بس وصف المسألة. لا تغيّرين اسم الدالة ولا الأمثلة، لأن الكود يبدّل الوصف فقط ويخلي الباقي مثل ما هو.

### أمثلة توضيحية للصيغة العراقية

هذي أمثلة كتبتها أنا لتوضيح الأسلوب فقط. الصيغ الحقيقية لازم يكتبها متحدثون عراقيون حسب المنهجية.

- **python/0** (فصحى: «تم تزويدك بقائمة عمليات الإيداع والسحب...»)
  عراقي، مستوى `medium`: «عندك ليستة بيها ايداعات وسحوبات من حساب بنك يبدي من صفر. شوف اذا الرصيد نزل تحت الصفر بأي لحظة، اذا نزل رجّع True، واذا ما نزل رجّع False.»

- **python/7** (قلب حالة الأحرف)
  عراقي، مستوى `light`: «عندك سترنك، الحروف الصغيرة سويها كبيرة والكبيرة سويها صغيرة.»

- **مستوى `heavy`** يعني لهجة ثقيلة بكلمات محلية، مثل: «دبرلي فنكشن تشيل التكرار من الليستة وتخلي كل رقم مرة وحدة.»

### قبل ما تكملين، تأكدي إن الجدول جاهز

```bash
python 01_prepare_data.py --check
```

يطلعلج شنو ناقص. لما يكتب `READY` كمّلي.

## الخطوة 2: الإرسال إلى ChatGPT

### الطريقة المجانية: موقع ChatGPT نفسه (يدوياً)

1. **سوّي صفحة الأسئلة:**
   ```bash
   python 02_manual.py export
   ```
   تطلع صفحة `results/manual_prompts.html`. نزّليها وافتحيها بـ Chrome على الحاسبة.

   قبل ما تكتبين العراقي، تكدرين تبدين بالإنجليزي بس:
   ```bash
   python 02_manual.py export --conditions english
   ```
2. **لكل سؤال بالصفحة:** اضغطي «انسخي السؤال»، والصقيه بمحادثة **جديدة** بـ chatgpt.com، وانسخي الجواب كامل والصقيه بالمربع. الصفحة تحفظ وحدها.
3. **بآخر كل يوم** اضغطي «نزّلي الأجوبة»، يطلع ملف `replies.json`.
4. **رجّعي الأجوبة للكود:**
   ```bash
   python 02_manual.py import replies.json
   python 03_evaluate.py
   python 04_analyze.py
   ```

**لما تسوين صفحة جديدة** (مثلاً بعد ما تضيفين العراقي)، افتحيها واضغطي «رجّعي ملف أجوبة» واختاري آخر `replies.json`. الأجوبة القديمة ترجع مكانها.

**للورقة:**
- الموقع ما يسمح بضبط temperature ولا تعليمة نظام. فكل سؤال يبدي بنفس التعليمة الثابتة، وكل سؤال بمحادثة جديدة، والذاكرة مطفية.
- سجّلي اسم النموذج اللي يظهر بالموقع وتاريخ التجربة.
- سؤال البحث الرابع (الترجمة للإنجليزي) ما داخل بهذي الطريقة.

> ملاحظة: GitHub Models انلغى بتموز 2026، فالطريقة المجانية الوحيدة هي الموقع.

### الطريقة المدفوعة: OpenAI API
1. سوّي مفتاح API من موقع OpenAI (platform.openai.com)، وحطيه:
   ```bash
   export OPENAI_API_KEY=sk-...        # في Windows: set OPENAI_API_KEY=sk-...
   ```
2. اختاري النموذج. اكتبي اسمه بالضبط مثل ما موجود بقائمة نماذج OpenAI، وسجّليه بالورقة مع تاريخ التجربة.
3. جربي أول شي على 5 مسائل بس:
   ```bash
   python 02_generate.py --model <اسم-النموذج> --limit 5
   ```
4. إذا كلشي تمام، شغّلي الكل:
   ```bash
   python 02_generate.py --model <اسم-النموذج>
   ```

**عدد الطلبات:** 80 مسألة × 4 صيغ × 6 ردود = 1,920 طلب، زائد 80 طلب ترجمة. الكلفة غالباً بضعة دولارات حسب النموذج، تأكدي من الأسعار الحالية قبل التشغيل.

**إذا انقطع النت أو وقف البرنامج:** شغّليه مرة ثانية بنفس الأمر. يكمّل من وين ما وقف، ويعيد بس الطلبات اللي فشلت.

**ماذا يحفظ:** كل رد بملف `results/generations.jsonl`، مع اسم النموذج اللي رجّعه الـ API ووقت الطلب.
- الرد رقم 0 بـ temperature = 0، وهو النتيجة الأساسية.
- الردود 1 إلى 5 بـ temperature = 0.8، وتنستخدم لحساب pass@k.

تعليمة النظام بالإنجليزي ونفسها لكل الصيغ، حتى يكون الفرق الوحيد هو لغة وصف المسألة. النص موجود بملف `common.py` تحت اسم `SYSTEM_PROMPT`، انقليه للورقة.

## الخطوة 3: التقييم

> ⚠️ هذي الخطوة تشغّل كود كتبه ChatGPT. شغّليها بجهاز افتراضي (virtual machine) أو حاوية (Docker)، أو على الأقل بحساب مستخدم منفصل ما بيه ملفات مهمة.

```bash
python 03_evaluate.py
```

ياخذ تقريباً دقيقتين لكل ألف رد. النتيجة بملف `results/evaluation.csv`، سطر لكل رد:
- **هل نجح بالاختبارات.**
- **سبب الفشل:** خطأ منطقي، أو استثناء، أو تجاوز الوقت.
- **درجة pylint.**
- **التعقيد الدوري.**
- **عدد الأسطر.**
- **لغة التعليقات اللي كتبها ChatGPT بنفسه.**

## الخطوة 4: التحليل

```bash
python 04_analyze.py
```

يطلع ملف `results/report.md` بيه جداول القسم ٤ جاهزة للنسخ:

| القسم | المحتوى |
| --- | --- |
| **4.1** | pass@1 وpass@5، مع اختبار McNemar بين كل صيغتين وتصحيح Bonferroni |
| **4.2** | جودة الكود، مع اختبار Wilcoxon |
| **4.3** | عدد المسائل اللي نجحت بالإنجليزي وفشلت بالعراقي |
| **4.4** | النتيجة حسب مستوى اللهجة |

### تصنيف الأخطاء (سؤال البحث الثالث)

الخطوة 4 تسوي ملف `results/error_annotation.csv`، بيه كل مسألة نجحت بالإنجليزي وفشلت بالعراقي، مع الكود وسبب الفشل.

1. مصنِّفان، كل واحد لوحده، يملون `annotator_1_category` و`annotator_2_category` بوحدة من هذي الفئات:
   - `dialect word misunderstood`
   - `partial understanding`
   - `ordinary logic error`
   - `non-code reply`
   - `other`
2. بعدها يتفقون ويكتبون `agreed_category`.
3. شغّلي:
   ```bash
   python 04_analyze.py --kappa
   ```
   يطلع معامل Cohen's kappa وجدول 4.3.

## تجربة الكود بدون API

إذا تريدين تتأكدين إن كل الخطوات تشتغل قبل ما تصرفين على الـ API:

```bash
python 02_generate.py --mock --samples 2
python 03_evaluate.py
python 04_analyze.py
```

وضع `--mock` يرجّع الحل الصحيح المرجعي بدل ChatGPT، فالنتيجة لازم تطلع 100%.

جربته قبل ما أسلمه: الحلول المرجعية نجحت بكل الـ 80 مسألة بالصيغ الأربع. بعد التجربة امسحي مجلد `results` حتى تبدين نظيف:

```bash
rm -rf results/*          # في Windows: del /q results\*
```

## ملاحظات للورقة

- **21 مسألة من الـ 80** بيها `literal_warning`. هذا خلل بترجمة HumanEval-XL الفصيحة: كلمات انترجمت والاختبارات تنتظرها بالإنجليزي. صححيها قبل التجربة، واذكري التصحيح بقسم المنهجية.
- **إذا النموذج ما يقبل ضبط temperature** (بعض النماذج الحديثة هيج)، الكود يكمل بالإعداد الافتراضي ويطبع تنبيه. سجّلي هذا بالورقة، ويصير الرد رقم 0 مجرد عيّنة أولى مو رد ثابت.
- **حتى temperature = 0 ما تضمن نفس النتيجة كل مرة** (Ouyang وآخرون، 2025). لهذا نحسب pass@k من عدة عينات.
