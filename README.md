# كود تجربة: أثر اللهجة العراقية على كود ChatGPT

هذا الكود ينفّذ منهجية الورقة كاملة، على أربع خطوات. كل خطوة ملف Python مستقل.

| الخطوة | الملف | ماذا يفعل |
| --- | --- | --- |
| 1 | `01_prepare_data.py` | يجهّز جدول المسائل الـ 80 لتكتبوا فيه الصيغة العراقية |
| 2 | `02_generate.py` | يرسل كل مسألة إلى ChatGPT بالصيغ الأربع ويحفظ الردود |
| 3 | `03_evaluate.py` | يشغّل الاختبارات ويقيس جودة الكود |
| 4 | `04_analyze.py` | يحسب الإحصاءات ويطلع جداول القسم ٤ من الورقة |

الصيغ الأربع هي: الإنجليزية، والفصحى، واللهجة العراقية، واللهجة العراقية بعد ترجمتها للإنجليزية (سؤال البحث الرابع).

المسائل مأخوذة من HumanEval-XL (رخصة MIT، الملف `data/HumanEval-XL-LICENSE`). فيه 80 مسألة Python متوازية بالإنجليزية والعربية الفصحى، مع اختباراتها.
